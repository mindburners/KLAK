Update firmware

Latest firmware: loading…
Your browser can't flash firmware. Please use Chrome or Edge on a computer. This page must be opened over https (it is on GitHub Pages).
  1. Connect KLAK to your computer with a USB data cable (not a charge-only cable).
  2. Click Install / Update KLAK and pick the serial port that appears.
  3. Click Install and wait until it says the installation is complete.
  4. Unplug and reconnect KLAK. The new version shows on the startup screen.
No port showing? Your computer may need a USB driver. Install the CP210x driver or the CH340 driver (newer boards), then try again.
